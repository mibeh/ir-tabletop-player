# CTEP AAR/IP Template

The DOCX mirrors CISA's CTEP After-Action Report / Improvement Plan template,
with two deletions and a neutral visual style.

## Document structure (in order)

1. **Title page** — exercise name, "Incident Response Tabletop Exercise —
   After-Action Report / Improvement Plan (AAR/IP)" subtitle, date.
2. **Exercise Overview** table — Exercise Name, Exercise Dates, Scope, Mission
   Area(s), Core Capabilities, Objectives, Threat or Hazard, Scenario, Sponsor,
   Participating Organizations, Points of Contact.
3. **Executive Summary** — a narrative that frames the exercise objectives and
   summarizes the most important strengths and areas for improvement.
4. **Analysis of Exercise Objectives** — intro + alignment table (Objective ↔
   Core Capability), then one section per objective: Objective N heading, Core
   Capabilities line, Strengths (bulleted), Areas for Improvement — each as
   Observation / Priority / Reference / Analysis / Recommendation.
5. **Appendix A: Improvement Plan** — landscape-oriented section (only this
   appendix; the rest of the document is portrait); matrix with columns:
   Exercise Objective, Core Capability, Issue/Area for Improvement, Priority,
   Corrective Action, Capability Element, Primary Responsible Organization,
   Organization POC, Start Date, Completion Date.
6. **Appendix B: Exercise Participants** — Name / Position / Exercise Role /
   Department table.

All tables use Word's "AutoFit Contents" layout so columns size to their text.

## Deleted relative to the CISA template

- Appendix B (Core Capabilities reference text) — removed.
- Appendix C (alternate AAR template) — removed.
- The CISA Participants appendix (their Appendix D) is renumbered to Appendix B.
- "This page is intentionally left blank" filler pages — dropped.

## Authoring guidance (faithful to the template's primary format)

- No HSEEP P/S/M/U performance ratings (that scale only appears in the dropped
  Appendix C).
- The Executive Summary is a short narrative for a leadership reader: the
  exercise objectives, then the headline strengths and areas for improvement.
- Strengths and Areas for Improvement are qualitative, grounded in transcript
  evidence.
- Each Area for Improvement (and its matching Improvement Plan row) carries a
  Priority of Critical, High, Medium, or Low, set by the risk and impact of the
  gap.
- A Recommendation states how to close a gap; the concrete corrective action
  with an owner and dates goes in the Improvement Plan matrix.
- Reference lists relevant playbooks/CIRP/runbooks where known, else
  "Not Applicable".

## Visual style

- Slate `#253746`: section heading text and table-header cell fills (white bold
  text in filled cells).
- Orange `#FF5500`: subtitle and sub-headings (Strengths / Areas for
  Improvement).
- Body font: Lato.
- Running header and footer: "TLP:AMBER+STRICT - CONFIDENTIAL".
